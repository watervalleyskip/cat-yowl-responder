# cat-yowl-responder

![Python](https://img.shields.io/badge/python-3.9%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)

YAMNet を利用した、夜間の猫の鳴き声（遠吠え）自動介入システム。

本プログラムはマイク入力を常時監視し、猫の鳴き声を検出すると段階的に強度を上げた威嚇音を自動再生し、すべてのイベントを記録して後から行動分析できるようにします。効果を保証するツールではなく、**行動実験ツール**として設計されています。音による介入が個々の猫に有効かどうかを検証すると同時に、鳴き声の原因（発情・餌の要求・注意を引くための行動）を特定する手がかりとなるデータを収集します。

## アーキテクチャ

```
       マイク入力
          │
          ▼
 スライディングウィンドウ (0.975 秒)
          │
          ▼
        YAMNet
  (AudioSet 521 クラス)
          │
          ▼
   対象クラスを検出？
          │
     ┌────┴────┐
     │         │
   いいえ     はい
     │         │
     ▼         ▼
   監視継続   応答クリップを再生
                 │
                 ▼
        クールダウン / ミュート制御
                 │
                 ▼
       CSV ログ + 音声スナップショット
```

## 主な機能

### リアルタイム鳴き声検出
Google の AudioSet で事前学習された YAMNet モデルを使用し、独自データセットの収集・ラベリングなしでマイク入力を連続分類します。

### 段階的応答戦略
ユーザーが用意した音声を A → B → C のエスカレーションチェーンに沿って再生し、鳴き声が続く場合はより強い応答へ段階的に移行します。

### エコーセーフ再生
再生中および再生後数秒間は検出を自動的に停止し、システムが自身の再生音に反応するループを防ぎます。再生素材と一致する **Hiss** クラスもトリガーから除外しています。

### 自動クールダウン
連続応答回数が設定値に達すると数分間強制ミュートし、過剰な刺激を防ぎます。一定時間静かな状態が続くと、エスカレーションチェーンはリセットされます。

### イベントログ
すべてのトリガーを CSV に記録します（タイムスタンプ、クラス、信頼度スコア、再生クリップ、鳴き止んだかどうか）。

### 音声保存
各トリガー前後数秒間の音声を保存し、誤検出・検出漏れを手動で確認できます。

### オフライン動作
初回の YAMNet ダウンロード後は完全にローカルで動作します。

## 動作の仕組み

- マイクが 16 kHz モノラル音声を常時キャプチャします。
- 音声は 0.975 秒のオーバーラップウィンドウで処理されます。
- 各ウィンドウを YAMNet（AudioSet 事前学習、521 クラス）で分類します。
- 対象クラス（**Caterwaul** / **Meow** / **Cat**）の信頼度が閾値を N ウィンドウ連続で超えた場合のみトリガーが発火します。
- エスカレーションチェーンに沿って対応する威嚇クリップを再生します。
- 再生後はクールダウンを経て監視を再開します。
- すべてのイベントは後の分析（`summarize.py`）のために記録されます。

## なぜ YAMNet か

YAMNet は Google の AudioSet データセットで事前学習された軽量な音声分類モデルで、521 種類の環境音クラスをカバーしています。ペットの行動分析向けに学習されたものではありませんが、**Caterwaul**・**Meow**・**Cat** を独立したクラスとして認識できるため、独自データセットの収集・ラベリングなしで実用的なゼロショット検出器として利用できます。

- Windows
- Python 3.9 以上

```
pip install sounddevice numpy tensorflow tensorflow_hub pygame
```

## 使い方

### 1. 応答クリップの準備

CC0 ライセンスの猫の威嚇音（ハーッ・唸り声）を収集します（freesound.org、Pixabay など）。長さは 2〜5 秒、人の声や BGM が入っていないものを選んでください。`sounds/` に配置し、`config.json` の `materials` に弱い順から並べて登録します。

### 2. PC のスリープを無効化（初回のみ）

```
powercfg /change standby-timeout-ac 0
```

### 3. 監視の開始

```
python yowl_responder.py
```

### 4. 前夜の振り返り

```
python summarize.py [YYYY-MM-DD]
```

あわせて `clips/` に保存された音声スナップショットを確認してください。

## 設定

ほぼすべての実行時パラメータは `config.json` で設定できます。

```json
{
  "thresholds": {
    "Caterwaul": 0.25,
    "Meow": 0.40,
    "Cat": 0.50
  },
  "consecutive_hits": 2,
  "burst_limit": 4,
  "forced_silence_minutes": 5,
  "volume": 0.9,
  "materials": ["hiss_A.wav", "hiss_B.wav", "hiss_C.wav"]
}
```

## チューニング

| 症状 | 調整方法 |
|---|---|
| 誤検出が多い | クラス閾値を上げる。**Cat** クラスを対象から外す。`consecutive_hits` を 2 → 3 に増やす |
| 検出漏れが多い | **Caterwaul** / **Meow** の閾値を下げる。マイクと猫の距離を確認する |
| 猫が反応しない | `volume` を夜ごとに少しずつ上げる。クリップを差し替える |
| 人間の睡眠を妨げる | `burst_limit` を下げる。`forced_silence_minutes` を増やす |

推奨デフォルト閾値：

| クラス | 閾値 |
|---|---|
| Caterwaul | 0.25 |
| Meow | 0.40 |
| Cat | 0.50 |

**Caterwaul** が主な検出対象ですが、このクラスに対するモデルの信頼度は系統的に低いため、最も低い閾値を設定しています。**Cat** は最も範囲が広く誤検出しやすいクラスのため、最も高い閾値としています。

## 制限事項

- 検出精度は個々の猫・マイクの配置・室内の音響環境に依存します。保存されたトリガー音声をもとに夜ごとに閾値を調整する必要があり、そのまま使える保証はありません。
- 音による介入は症状への対処であり、原因の解決ではありません。トリガーが毎日早朝の同じ時間帯に集中する場合、猫は餌を要求している可能性が高く、自動給餌器の方が原因に直接対処できます。
